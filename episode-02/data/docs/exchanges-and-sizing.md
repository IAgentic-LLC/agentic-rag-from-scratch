# Exchanges and Sizing
Owner: Customer Experience. Last reviewed: 2026-06-02.

## Size exchanges
Regular catalogue items can be exchanged for another size within 14 days of delivery, once per order, subject to stock. Limited drop items cannot be exchanged; they can only be returned inside the drop window.

## Sizing advice
Air Glide runs half a size small, so most customers go up half a size. Volt Runner fits true to size.

## Exceptions
EU customers keep the legal right of withdrawal, so they can return a drop pair within 14 days instead of exchanging it.
